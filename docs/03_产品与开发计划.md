# 知构产品与开发计划

版本：1.0｜基线日期：2026-10-31｜状态：实施中

## 目标与确定范围
个人离线 Android 学习工具，帮助非科班、熟悉企业信息化的 IT 项目经理理解软件工程并评审 AI 交付。学习成果是能解释、判断、提出问题与核验。

- Android 10+ 手机，竖屏优先，支持大字体、深浅主题。
- 正式 MVP 为 C00～C72 共 73 章、15 篇、八个附录；每章原则 8～12 题，约 584～876 题。
- 目录及前置、关联导航；不做关系图。课程随 APK 更新，学习数据手动备份恢复。
- 首版不做账号、云同步、在线 AI、通知、笔记、划线和课程包导入。
- 样板章节开发版不算正式 MVP，发布版本为 v0.1.0 前必须满足全部门槛。

## 完整 MVP 功能与规则
| 功能 | 验收行为 |
|---|---|
| 首页 | 继续阅读、已读数量、待复习错题、近期练习、首次学习方法 |
| 目录 | 按篇展示全部章节，深度/优先级/阅读状态/自测结果，允许跳读 |
| 阅读 | 本地标题、列表、表格、代码、图片、章内导航；各章阅读位置、上下章、前置与关联跳转 |
| 已读 | 手动设置，进入页面和滚动不能自动改变 |
| 搜索 | 章名、正文、附录，显示片段并定位正文；不搜题库 |
| 书签 | 章节收藏及集中查看 |
| 练习 | 默认本章全部题，逐题提交即时解析，显示每个选项依据、误区和知识点 |
| 自测 | 单章/多章/已读范围默认 20 题，不足全取；交卷后解析；未答提示后计错 |
| 错题 | 答错进入，复习正确订正、再错恢复待复习；保留历史、章节筛选 |
| 记录 | 模式、时间、题目版本、选择、成绩；未完成会话可继续 |
| 进度 | 阅读率、各章最新自测、累计作答、待复习数；不推断能力掌握 |
| 设置 | 字体、主题、版本、导出恢复、确认后清空 |

单选/多选全对得分，重复提交只计一次。练习与自测共用题库，仅供自查。阅读、成绩、错题独立。

## 工程与数据约定
Kotlin、Compose Material 3、ViewModel/StateFlow、Room、DataStore；单 app 模块，Repository 统一读写。包名 `com.sk5416.zhigou`，minSdk 29。SDK 和依赖锁定稳定版本。

正文 Markdown，元数据/题库 JSON；构建生成 HTML，WebView 关闭脚本、远程加载和任意文件访问，通过本地资源加载器呈现。应用不申请网络权限，禁用系统云备份。

Room 保存课程索引、阅读、会话、作答、错题；DataStore 保存偏好。课程/题目编号永久稳定。App、课程、数据库各自版本；题意/答案变化提升题目修订号，旧记录保留，不当新版成绩。修订影响未完成会话时要求重新开始，不静默替换答案。

备份：系统文件选择器导出版本化 JSON，含学习数据与偏好、不含教材。恢复先完整校验及预览，再确认整体替换；失败保留旧数据。新版 APK 同包同签名覆盖升级，数据库显式迁移。密钥本机保管、独立备份，不入库。

## 验证与交付
- 内容检查：唯一编号、合法题型答案、逐项解析、知识点及章节引用、先修无环、本地资源和完整规模。
- 逻辑测试：答案集合、防重、未答交卷、订正、版本变化、抽题边界。
- 数据测试：进程回收、会话恢复、备份往返、损坏/不兼容备份、事务失败、旧版数据库升级。
- 设备测试：Android 10、最新稳定 Android 模拟器和实际手机；飞行模式首次启动、全部本地内容、系统返回、小屏、大字和主题。
- 构建：内容检查、单元测试、Lint、APK；GitHub Actions 保存开发 APK，正式版本标签记录基线。
- 内容审核：逐章核对十项教学要素、题目互异/答案/干扰项；安全/API/数据库/AI 重点审核。厂商事实需来源和日期，模拟案例明确标注。
