# 手机试用验收

适用于dev.9开发验证版。课程已齐备；本表用于补充真实手机体验，不代表已经发布正式MVP。模拟器结果见`04_验收记录.md`。

## 安装前

如果手机已有知构和学习记录，先在设置导出备份并确认文件已保存。使用同一来源、同一签名的新包覆盖安装，保留旧App；不要为安装失败而直接卸载。GitHub临时开发包与本机交付包可能签名不同，不能混作一条升级链。

本机交付包：`.artifacts/知构-0.1.0-dev.9.apk`，SHA256见`.artifacts/SHA256-dev.9.txt`。打开设置应显示`0.1.0-dev.9`、课程`2026.10-complete.1`。

## 建议顺序

| 检查 | 操作与预期 |
|---|---|
| 离线 | 开飞行模式后启动；目录、正文、图片、题目和解析可用 |
| 阅读导航 | 搜索C72或正文词句、进入章节；上下章、章内导航和关联章节可打开；返回操作符合预期 |
| 已读与书签 | 标记一章已读、收藏；回目录查看对应状态，书签筛选可找到；阅读率不随答题自动改变 |
| 单选与多选 | 点击整行选项；多选可选多个、再次点击可取消；提交后显示正确答案及每项解释，连点不重复计分 |
| 自测 | 选一章自测，留一题未答后交卷；出现未答提示，取消可继续，确认后未答计错 |
| 错题 | 答错后到复习页；按章查看并答对订正，历史记录仍保留 |
| 中断后继续 | 未完成练习选好答案、切到下一题，回桌面后重开；可继续，题号和选择保持 |
| 字体主题 | 切换深浅色、调整正文字号；小屏上长表格可横向查看，选项与按钮可滚动到达 |
| 读屏体验 | 若使用TalkBack，核对正文、列表和表格是否能完整朗读；Android17自动可访问树曾缺少正文，当前未将此项标为通过 |
| 备份保存 | 设置导出，系统选文件界面选择位置；完成后出现成功提示，可在该位置找到文件 |
| 取消恢复 | 选择刚才的备份，核对预览记录数后取消；现有记录不变 |
| 确认恢复 | 在愿意替换当前记录时使用已保存备份恢复；完成提示出现，阅读、书签、练习、错题和设置与备份一致 |
| 清空保护 | 打开清空确认后选择取消，确认记录仍在；不必为了试用删除自己的学习数据 |
| 覆盖升级 | 已有dev.8记录时直接安装同来源dev.9；阅读、书签、未完成练习、成绩和设置继续保留 |

不需要为了测试向AI上传个人备份。若出现问题，反馈手机型号、Android版本、操作步骤、对应章节/题号、预期与实际即可。异常界面可附不含个人信息的截图。
