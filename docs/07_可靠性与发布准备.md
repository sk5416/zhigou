当前仍使用此前同机开发签名。正式v0.1.0需同时完成：

1. 本批验证通过，并记录失败修复过程及实际范围。
2. 用户实际手机安装、阅读/练习、备份和覆盖升级体验验收。
3. 正式密钥安全保管及独立备份核对；密钥、口令及个人备份不入库或公开产物。
4. 明确开发签名到首次正式签名的迁移方案；不因签名不同擅自卸载或删除已有学习记录。正常同签名后续版本使用覆盖安装。
5. 最终签名APK、SHA256、功能说明与版本标签一致。以上未完成前不发布正式MVP。

本机有中文目录时，与Gradle一样通过英文目录联接调用脚本，例如E:\tdl-ai-project\zhigou-workspace\tools\package_release.ps1。Windows签名入口为`tools/package_release.ps1 -KeystorePath <项目外路径> -KeyAlias <别名>`。口令仅通过ZHIGOU_STORE_PASSWORD/ZHIGOU_KEY_PASSWORD环境变量传入签名工具，不写日志或配置。脚本先执行Release测试/Lint/完整内容构建，检查正式版本号、包名及无网络权限，再对齐、签名、验证、生成SHA256，拒绝覆盖同名发布包。

该入口已编写；当前dev.8带开发版本标记，会拒绝作为正式签名交付。正式密钥与独立备份尚未生成或验收，不能把脚本存在写成签名成功。脚本不负责对外发布或创建标签。
