# 知构

面向个人的 Android 离线学习 App：阅读课程、做题检验、错题复习、记录进度。课程为《AI 时代技术型 IT 项目经理：Vibe Coding 所需的软件工程全景》，重点帮助具备企业信息化经验的学习者判断技术边界、识别风险、核验 AI 交付。

**当前状态：开发中，尚未发布正式 MVP。下表是首个 MVP 的完整功能基线，不代表全部已验收。**

当前开发版 `0.1.0-dev.2`：已实现学习闭环页面与本地持久化，内置 **C00～C05、C10～C15 共 12 章、96 道题和八个速查附录**。导学、系统基础、网络与 API 三篇已齐，C06～C09、C16～C72 共 61 章尚未交付。当前内容已作逐章作者自审，记录与文件指纹绑定，不代表独立专家认证；未完成正文不展示为空白教材。

## 首个 MVP 完整功能
| 功能 | 说明 |
|---|---|
| 离线课程 | 15 篇、C00～C72 共 73 章、8 个附录；教材、图片、题目、答案与解析全部内置 |
| 首页 | 继续阅读、已读数量、错题待办、近期练习和首次学习指引 |
| 课程导航 | 按篇浏览、深度/优先级标签、前置与关联章节、自由跳读 |
| 阅读 | 表格、代码、图片和章内导航，逐章阅读位置、上下章切换 |
| 手动已读 | 自主标记完成；不将浏览、滚动或自测通过自动算作已读 |
| 全文搜索 | 课程及附录标题/正文搜索、片段展示、定位内容，不检索题库 |
| 章节书签 | 收藏章节、集中查阅 |
| 章节练习 | 每章原则上 8～12 题，单选/多选；逐题显示正确答案、每个选项解析、误区、知识点 |
| 自测 | 一章、多章或已读章节，默认随机 20 题，不足全取；交卷后解析 |
| 错题复习 | 自动收录，按章筛选，复习正确订正，再错重新待复习，保留历史 |
| 会话恢复 | 保存未完成练习、自测选择；重启后继续 |
| 练习历史 | 模式、时间、选择、题目修订版本与成绩 |
| 学习进度 | 阅读完成率、每章最新自测、累计作答与待复习数分别统计 |
| 阅读偏好 | 字体调整、系统/浅色/深色主题 |
| 备份恢复 | 系统文件选择器导出学习数据及设置；校验预览后整体替换恢复；失败不破坏原数据 |
| 清空数据 | 明确确认后清空个人记录与设置，不删除课程 |
| 离线升级 | 安装同签名新版 APK 更新教材和功能，保留记录；题目修订后区分新旧成绩 |

多选题采用答案集合完全一致判分，不给部分分。交卷前提示未答数量，确认后未答计错。重复点击不重复计分。练习与自测共用题库，仅用于自查，不代表独立能力认证。

Android 10+ 手机优先，无账号、联网、云同步、分析服务；首版不做笔记、划线、提醒、在线 AI、关系图及课程包导入。

## 安装、升级与数据
正式 APK 尚未交付。开发 APK 位于 `app/build/outputs/apk/debug/app-debug.apk`，亦可从 GitHub Actions 成功构建的产物下载。开发版本不能视作完整 MVP。

拿到 APK 后允许系统安装所选文件即可。升级需使用同包名、同签名的新 APK，直接覆盖安装；不要卸载旧版。卸载会删除应用内部记录，手动导出的备份文件不受影响。

本机交付的 dev.1 与 dev.2 使用同一本机开发签名；云端 Debug APK 可能使用不同临时签名，不应与本机包混用覆盖升级。正式发布将使用独立持久签名。

在设置中导出备份到自行选择的位置。恢复将替换现有全部学习记录和偏好，先检查预览再确认。备份不是教材包，不包含课程正文；备份可能包含学习行为，请自行保管。当前单份备份上限 20MB，导出前与导入时都校验。应用关闭系统云备份。

正式签名密钥在本机单独保存和备份；仓库及公开产物不包含密钥、密码、本机配置或个人备份。

## 构建和验证
需要 JDK 17、Python 3.12+ 和 Android SDK（platforms;android-35、build-tools;35.0.0）。将 SDK 路径写入不入库的 `local.properties`，或设置 `ANDROID_HOME`。依赖已固定：AGP 8.9.2 / Gradle 8.11.1 / Kotlin 2.1.20 / Compose BOM 2025.04.01 / Room 2.7.1。

```text
python -m pip install -r requirements.txt
python tools/content.py check
python tools/content.py check --reviewed
python -m unittest discover -s tools/tests -v
./gradlew testDebugUnitTest lintDebug assembleDebug
./gradlew connectedDebugAndroidTest
```

Windows 使用 `gradlew.bat`。若中文项目路径导致测试类加载失败，使用指向本目录的英文目录联接运行；本机已建立 `E:\tdl-ai-project\zhigou-workspace`。原始文件仍在当前目录，勿复制维护两套源码。

`python tools/content.py check --release` 要求 73 章、八附录全部交付并有逐章审核记录；Release 构建也执行该门槛，目前应失败。`tools/init_catalog.py` 和 `tools/author_sample_questions.py` 仅为首次初始化保留，会拒绝覆盖已有内容，日常直接编辑 content 源文件。

`check --reviewed` 检查已交付内容的审核记录是否与正文、题库、章节元数据和本章来源匹配。任何一项改变后先复核再更新记录，不能只重新计算指纹。该命令不能自动判断事实与教学质量。

GitHub Actions 包含构建/检查和 API 29 设备测试两项任务，设备任务与本地单测分别报告。当前没有旧版正式数据库基线，因此不声称已验证跨版本数据库升级；今后数据库变化必须添加迁移和对应测试。
