## 重要先修路径

1. 系统组成 → 网络与 HTTP → API 契约 → 超时、重试和幂等 → 企业同步状态与对账。
2. HTTP 与 HTTPS → 身份认证 → 服务端授权和数据范围 → 权限反例测试。
3. 数据建模与约束 → 事务并发 → 迁移、备份和恢复 → 发布兼容性。
4. 代码阅读与异常 → Git 改动审查 → 自动测试证据 → AI 代码与依赖评审。
5. 上述能力 → C67～C72 物料同步综合案例，验证从需求到交接的全过程。

先修关系用于学习引导，不锁定章节。已有 ERP 与 SQL 经验可以通过自测跳读熟悉部分，但不应因此跳过并发、恢复、权限等工程问题。

## 容易混淆的概念组

| 概念组 | 判断要点 |
|---|---|
| Authentication / Authorization | 你是谁，与能做什么分别设计 |
| Hash / Encryption / TLS | 摘要、可解密保护与传输协议不是同一作用 |
| Session / JWT | 会话状态管理与一种令牌格式不是互斥的万能选项 |
| CORS / 服务端授权 | 浏览器跨源控制不证明接口有业务权限检查 |
| Retry / Idempotency | 再做一次的动作，与重复不会重复产生副作用的性质不同 |
| Backup / Restore | 备份产物存在，与恢复经过验证不同 |
| Monolith / Microservices | 部署与协作取舍，不是软件质量高低标签 |
| Commit / Release | 一次代码快照与可交付版本基线不同 |
